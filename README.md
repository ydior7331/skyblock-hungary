# Skyblock Hungary (SHU)

Landing page for the Hungarian Hypixel SkyBlock guild Skyblock Hungary.

Live: https://ydior7331.github.io/skyblock-hungary/

Three designs, switchable from the button in the bottom-left corner (the choice is remembered):

- `index.html`: Égi szigetek
- `ejszaka.html`: Éjszaka
- `klasszikus.html`: Klasszikus (the first pixel-art version)

Placeholders to fill in: `DISCORD_INVITE` and `REQ` near the top of the first script in each page, plus the yellow-highlighted `.ph` texts.
